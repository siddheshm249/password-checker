# 🔐 Password Strength Checker

A tiny web app that rates a password as Weak, Fair, Good or Strong.

## How it is scored
One point each for: length 8+, length 12+, upper and lower case, a digit, a symbol. Common passwords score 0.

## DevOps
- Git + GitHub for version control
- Unit tests: `npm test`
- GitHub Actions: test, then deploy to GitHub Pages

## Run locally
Open `index.html`, or run `npm test`.
